# Preserved hero exploration

Branch: `features/codex/hero-role-studies`.

Run `pnpm dev --port 3010`, then open `/hero-study/explore?option=2`.

The selector contains the basic current composition (01), all reference directions
(02–06), and five alternatives (07–11). CTA and ASCII choices can be mixed.
The selected main-page direction is reference option 04, with the subsequent
mobile hierarchy, contact links, glyph hover restoration, and ASCII refinements.

This branch preserves the complete comparison board, screenshot assets, older
study routes, and the final main-page version. The production MR intentionally
omits the study routes and their generated comparison assets.
